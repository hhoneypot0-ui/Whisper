# 「悄悄」Android App 构建说明

这个项目**只用 Android 系统 API，没有任何第三方依赖**，所以很小（约 30KB APK），构建也快。

---

## 方式一：Android Studio（推荐，图形界面）

**1. 装 Android Studio**
官网 https://developer.android.com/studio ，下载安装，一路下一步。首次启动会自动下载 SDK（约 2-3GB，等它跑完）。

**2. 打开项目**
Android Studio → `File` → `Open` → 选中解压出来的 `qiaoqiao-app` 文件夹 → 打开。

首次打开会提示同步 Gradle（右下角有进度条），等它跑完。如果提示缺少 SDK，点提示里的链接让它自动装。

**3. 改接口地址（如果你换了域名）**
打开 `app/src/main/java/cc/ccwu/bierlan/qiaoqiao/MainActivity.java`，第 30 行左右：

```java
private static final String START_URL = "https://im.bierlan.ccwu.cc";
```

改成你自己的地址。

**4. 生成 APK**
菜单 `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`

等右下角提示 `APK(s) generated successfully`，点 `locate` 就能找到文件。

**位置**：`app/build/outputs/apk/debug/app-debug.apk`

把这个文件传到手机安装即可。

---

## 方式二：命令行（不装 Android Studio）

需要：**JDK 17** + **Android SDK**（含 build-tools 34 和 platform 34）

**1. 准备 SDK**

装好 Android SDK 后，在项目根目录建一个 `local.properties`，写上你的 SDK 路径：

```properties
# Windows（注意路径里的反斜杠要写两个）
sdk.dir=C\:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk

# macOS
sdk.dir=/Users/你的用户名/Library/Android/sdk

# Linux
sdk.dir=/home/你的用户名/Android/Sdk
```

**2. 构建**

```bash
# Windows
gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug
```

> 第一次运行 `gradlew` 会自动下载 Gradle 8.7（约 130MB），耐心等。

**3. 产物**

`app/build/outputs/apk/debug/app-debug.apk`

---

## 装到手机

把 APK 传到手机（微信文件传输助手 / 数据线 / 网盘都行），用文件管理器打开点击安装。

**手机会提示"未知来源"**——允许一次就行，自己签的包都是这样。

---

## 这个 App 做了什么

它本质是一个**原生外壳**，里面加载你的网站 `https://im.bierlan.ccwu.cc`，但补上了浏览器拿不到的能力：

| 能力 | 说明 |
| --- | --- |
| 麦克风权限 | 发语音消息时直接可用，不用每次授权 |
| 文件选择 | 发图片/文件走原生选择器 |
| 通知权限 | 消息提醒 |
| 返回键 | 先退回上一级页面，不是直接退出 |
| 外链 | 站外的链接丢给系统浏览器打开 |

**界面、功能全部来自线上网站**——也就是说，你在服务器上改了网页，App 里立刻就变，不用重新打包。
